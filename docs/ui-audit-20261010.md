- An untitled special-song slot serialized its assignee as a song title in bulk
  preparation input. Keep that field empty until a title exists; retain the
  assignee and authoritative linked-song title. The existing local fix and its
  regression test are incorporated in this release.
- Local-only sidebar width and light-theme separator refinements caused visible
  differences from production. Adopt the existing 260px desktop width and 16%
  light separator consistently, retaining compact portrait drawer behavior.
- The calendar-assignee creation fixture still mocked retired direct table writes.
  Update it to exercise one atomic aggregate creation per service and load the
  current source serializer. Confirm assigned people, explicit clears and failure
  preservation. No production persistence code is changed.
- Navigation documentation still claimed the worship icon opened all services.
  The later `91fba0fd` decision deliberately opens the weekly board. Reconcile
  documentation without reverting the user's navigation behavior.
