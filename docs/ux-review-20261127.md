# Mindex 전역 UX/UI 검토 · 2026-11-27

기준은 공개 1.0.20 `b4cda35a`다. 앱 shell, 예배 controller, 배경 관리,
섹션 편집기, 미저장 확인, 서버 보관 상태와 업데이트 안내를 실제 renderer로
검토했다. Presenter output·인쇄 주보·운영 데이터는 디자인 변경 대상에서 제외했다.

## 이번에 정리한 항목

- 업데이트 안내, 서버 보관 실패와 일반 toast가 각자 같은 화면 좌표를 쓰던 구조를
  하나의 feedback rail로 합쳤다. 동시에 나타나도 겹치지 않고, 우측 패널이 열린
  Presenter에서는 기존 260px 보조 열을 따른다.
- 예배 배경 관리의 native file input이 `Choose File / No file chosen`처럼 OS·엔진별
  문구로 튀던 부분을 Mindex의 `파일 선택` control로 감쌌다. 실제 input은 유지해
  키보드 접근과 OS picker, 선택 파일명, 업로드 경로를 바꾸지 않는다.
- feedback와 file control의 radius, inset, icon, hover/focus를 기존 5/10px rhythm,
  16px icon, 35px control 계약에 맞췄다. 새로운 surface나 accent 의미는 만들지 않았다.

## 검토 후 유지한 항목

- 좌·우 panel 260px, topbar 50px와 40px action slot은 현재 계약과 일치한다.
- Presenter toolbar의 슬라이드/발표자 보기, 배율, BGM, 도움말, 주보는 서로 다른
  기능 그룹이므로 하나의 긴 segmented control로 합치지 않는다.
- 섹션 editor의 760px floating dialog, 30px dense field와 35px 일반 action 구분은
  좁은 화면에서도 입력을 가리지 않으므로 유지한다.
- `입력 필요`는 box 없는 warning text, 비활성 control은 neutral opacity를 유지한다.

## 다음 품질 묶음

1. 홈·전역 검색의 section label을 장식적인 pill 대신 accent 기준선과 단순한 label로
   정리했다. 상세 검색의 긴 검색어·찬양 제목·설명은 말줄임 대신 가용 폭에서 줄바꿈한다.
2. empty heading의 영문식 uppercase·강제 자간을 제거했다. toast는 hover뿐 아니라
   keyboard focus 중에도 자동 닫힘이 멈추며, offline fixture에서 두 엔진으로 검증한다.
3. Praise 편집·버전 비교와 Scripture 읽기는 320/390/768/1024/1440px에서 overflow와
   control geometry를 대조했고 기존 역할별 밀도를 유지했다.
4. 주보 workbench와 Remote는 각각 print/mobile 계약에 맞춰 검토했다. 주보 로고·
   표지 그림은 공통 `파일 선택` control로 통일하고, Remote 고정 장 넘김 아래에는
   연결 종료 action을 가리지 않는 safe-area 여백을 확보했다.
5. 실제 방송 장비 화면, 출력 영상과 음향은 browser visual audit와 구분한다.
