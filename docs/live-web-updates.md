# 켜 둔 웹앱의 안전한 업데이트

공개 웹과 Chrome 설치형 앱(PWA)은 같은 버전 확인 경로를 쓴다.
새로 켤 때뿐 아니라 30초마다, 창 복귀·연결 복구 때 같은 origin의
`mindex-release.json`을 캐시 없이 확인한다. 연속 두 번 확인된 새 버전만
적용한다. 실패·잘못된 응답·오프라인이면 현재 화면을 유지한다.

새 버전이 있으면 편집창을 가리지 않는 상태 안내를 표시한다.
다음 조건을 모두 만족하고 마지막 입력·클릭·스크롤 후 5초가 지난 뒤
현재 주소와 문서 연결을 유지하여 새 버전을 자동으로 연다.

- 예배·찬양·말씀·참고자료와 현재 주보뿐 아니라 열어 둔 다른 주보도 미저장 수정이 없다.
- 서버 보관과 기기 간 초안 전달에 미완료 요청·오류·충돌이 없다.
- 입력 포커스·한글 조합·드래그·확인창·저장·불러오기·자료 가져오기가 진행 중이지 않다.
- 인쇄·재생·송출이 진행 중이지 않다.

업데이트를 위해 사용자 자료를 자동 저장하거나 초안을 삭제하지 않는다.
미저장 내용이 있으면 편집 상태를 그대로 유지하며, 사용자가 기존 저장
경로로 저장하고 작업을 마치면 자동 적용한다. 보관 요청의 큐 수락을
저장 성공으로 취급하지 않는다. 적용 직전 모든 차단 조건을 다시 확인한다.
새 페이지는 기존 저장본과 기존 탐색 복원 경로를 그대로 사용한다.

Electron 설치본의 바이너리 업데이트는 기존 전용 갱신 경로를 유지한다.
송출 창에서는 이 웹 갱신 모듈을 시작하지 않는다. localhost 실행도
같은 origin의 제공 파일만 확인하며 공개 서버로 연결을 바꾸지 않는다.

검증: `test_live_update.cjs`, Chromium/WebKit `smoke_live_update.py`의
실제 두 버전 탐색·입력 중 보존·서버 저장 대기·숨은 주보 초안·작업 중
차단·저장된 문구와 줄바꿈의 갱신 후 복원. 기존 주보 입력과 서버 보관,
초안 전달 검사도 유지한다.
