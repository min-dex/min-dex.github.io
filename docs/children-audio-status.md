# 어린이 찬양 핵심 기능 현황

기준: 2026-10-20. 사용자 결정에 따라 핵심 기능 통합을 완료한 상태로 관리한다.
다른 앱의 모든 기능과 구현 방식을 재현하는 것은 완료 기준이 아니다.

## 현재 지원

- 곡 버전에 음원·가사 페이지·타이밍·지문을 함께 보관한다. 음원 불러오기 방식에서만 적용하며 일반 가사·악보의 사용자 송폼은 유지한다.
- 38곡 자동 넘김 활성화와 검증 범위는 `children-seven-sync-completion-20261018.json`을 따른다.
- 음원 싱크 유형에서 제목의 P 재생, 수동 탐색 후 R 자동 넘김 복귀를 지원한다. 수동 탐색 중 음악은 유지한다.
- 타이밍 기록·미리 듣기·위치 이동·보수적 박자 후보 분석·선택적 박자 맞춤·±0.2초 조정을 지원한다.
- 페이드아웃 정지 체크박스는 기본 켜짐이며 서버 상태 저장을 사용한다. 명시적 정지에 적용하고 일시정지는 즉시 처리한다.
- 어린이부 봉헌기도자/헌금위원과 운영표를 양방향 atomic save로 연결한다. 교사 표기와 다른 부서의 연결 규칙은 현행 담당자 계약을 따른다.
- 예배 편집·저장, 성경 조회, 미디어 입력과 송출은 민덱스의 기존 기능을 사용한다.

## 검증 범위

자동 분석 및 Chromium/WebKit 검증은 직접 청음이나 물리 PA·송출 장비 검증을 대신하지 않는다.
과거 주차 기록·배경·봉헌 영상·명단 전체의 운영 DB 이관까지 이 문서로 보증하지 않는다.
완료 범위와 날짜별 검증·출처 근거는 기존 배포 및 데이터 검증 기록을 보존한다.

## 후속 방향

[예배 조작·장비 연동·방송 송출 아이디어](presenter-control-ideas.md)를 별도 기획으로 관리한다.
원격 조작과 발표자 집중 보기는 구현·배포됐다. 원격의 현행 연결·복구 계약과
실기기 검증 한계는 [원격 조작 계약](presenter-remote-design.md)을 따른다.
순서별 음향·조명 자동 조작과 영상 입력·자막 합성·직접 방송 송출은 별도 기획이며
구현·배포된 것으로 표시하지 않는다.

성경책 쪽수와 전체 예배 PNG 내보내기는 후속 할 일에서 제외한다.
고급 애니메이션 구현 차이도 필수 잔여 작업으로 취급하지 않는다.
사용 중 발견된 불편·오류를 우선하며, 기존 Keynote 이미지 반입은 유지한다.

## 내부 정리

### 전례문·순서·선택 미리보기 계약 ·2026-10-26

- 예배의 부름은 담당자 제목이 아닌 전례문 본문이다. 어린이부 기본 본문은
  교회 원본 `Elem_2026-08-09.pptx` slide68 및 `Elem_2026-08-16.pptx`
  slide64의 동일 문구·줄바꿈을 따른다. 직접 입력한 본문과 명시적 비움이 우선한다.
- 설교 뒤 응답은 공통 `결단` 섹션의 `결단기도` 요소로 구성한다. 기존
  `decision`/`response_prayer` 역할만 정규화하며, 별도 대표기도를 위치로 추측하지 않는다.
  기존 요소 ID·담당·메모·순서·삭제 상태는 유지하고 새 항목을 덧붙이지 않는다.
- 송출 대기 중 우측 미리보기와 번호는 선택 카드에 맞춘다. 송출 중에는
  실제 송출 위치·암전·실시간 말씀을 계속 표시한다. 선택만으로 출력 창을 열지 않는다.
- 원본 Keynote의 페이지 수와 실제 애니메이션 유무를 구분한다. 이 날짜에
  사용한 24장 원본에는 눈에 보이는 build 효과가 없으며, 효과·영상·음원
  회귀 자료의 검증을 이 원본의 효과 검증으로 표시하지 않는다.

위 계약의 코드/로컬 검사와 공동 배포·운영 확인은 각각 별도로 기록한다.
