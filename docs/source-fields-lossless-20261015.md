- 송폼 필드 부재와 명시적 빈 값을 구별한다. 빈 값은 기존 송폼을 삭제한다.
- 광고 UI와 원문 적용이 공통 영역 갱신 함수를 사용한다. 새 광고 복원과 본문만 수정하는 테스트도 포함한다.

## 배포본 첫 시험에서 발견한 필터 보완

첫 배포 8d4b49d3에서 신규 plain_text/body 항목이 원문 Apply 후보 필터에서 제외되는 문제를 발견했다. 테스트 예배의 미저장 편집만 폐기했다. `source-` 구역의 명시적 원문 항목은 전용 인라인 편집기가 없어도 원문 반영/내보내기 대상으로 유지하도록 보완하고, 전체 Apply 경로와 후보 필터를 통과하는 통합 테스트를 추가했다. 기존 예배는 수정하지 않았다.

## 실제 저장·재로딩의 화면 경계 보완

테스트 예배의 revision 2에서 광고/일반 텍스트/곡 연결 저장은 보존됐으나, 수동 가사 본문을 재로딩할 때 내부 빈 줄로 화면이 다시 분리되는 것을 확인했다. 본문을 중복 저장하지 않고 `config.bodySlideLengths`에 화면별 UTF-16 길이만 기록하도록 보완했다. 복원 시 총 길이와 구분자 일치를 검증하고, 메타데이터가 없거나 손상된 기존 데이터는 기존 읽기 경로를 유지한다. 원래 화면 경계를 추측해 기존 예배를 변경하지 않는다.
