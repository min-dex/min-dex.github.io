# 1.0 비공개 적용 후보 · 2026-10-31

기준: 공개 `befc8730`. 이 후보는 운영 배포하지 않는다. 제품 버전 0.1.1,
channel development를 유지한다. 기존 Dawn 자산을 로딩 화면과 native icon 설정에
연결하고, 홈 소개·업데이트 안내 코드를 준비했다. 원래 preview 및 그 저장 키는
실앱으로 가져오지 않았다. `product-release.json`에는 현재 구현에 맞춘 한국어
변경 사항을 기록한다. 방송/YouTube 직접 송출 완료를 주장하지 않는다.

## 저장·실행 계약

- 홈 접기: 기존 MindexDisclosure, session 서버 상태, 독립 product/home-intro 키.
- 업데이트 확인: 기존 MINDEX_SERVER_STORAGE의 device 서버 상태,
  mindex.product.releaseSeen.v1 키. 문서·초안·로그인 데이터를 읽거나 덮어쓰지 않는다.
- 자동 안내: 검증된 build receipt의 channel=release와 productVersion에 연결.
  개발/테스트에서는 수동 보기만 가능. 로딩 중·저장소 미준비·다른 dialog·입력 중에는
  자동으로 열지 않는다. 현장 송출 화면에 안내를 삽입하지 않는다.
- 읽기 실패는 홈 진입을 막지 않으며 수동 버튼으로 다시 읽는다. 확인 저장 거절은
  기존 서버 상태 재시도/충돌 UI에 맡긴다. 닫기·포커스 복귀는 즉시 가능하다.
- native icon은 고정 dark 후보. webpage 테마로 OS 아이콘을 자동 변경하지 않는다.
- 운영 활성화 전 원소별 검토와 최종 조합 SHA의 필수 CI가 필요하다.

## 출시 수용표

| 대상 | 준비/근거 | 다음 외부 확인 |
|---|---|---|
| 웹 Chromium/WebKit | 격리 홈·첫 실행·저장 거절·초안 보존 검사 | 최종 공개 SHA 실기기 |
| macOS Apple Silicon | 기존 unsigned 격리 실행 기록; 현재 후보와 다른 소스 | 최종 signed/notarized 설치 |
| macOS Intel | 패키지 CI 경로 있음 | 실제 Intel 설치·출력 |
| Windows x64 | NSIS/test CI 경로 있음 | 실제 설치·종료·재실행·출력 |
| 첫 설치 | 기존 제품 없음 전제의 acceptance | 코드 서명·공증 확인, 새 프로필 진입 |
| 기존 사용자 업그레이드 | 이전 signed→신규 signed와 동일 제품 식별 필요 | 세션·설정·초안 보존 및 실패 복구 |
| 방송·현장 | 로컬 시제품 검증은 별도 | 캡처/믹서/CH8/YouTube 수신·동기 |

운영체제 최소 버전은 현재 설정만으로 지원 보증하지 않는다. 최종 Electron 버전과
실제 대상 장비를 확정해 별도로 기록한다. Mac ARM/Intel와 Windows x64는 목표 대상이며
세 플랫폼 실기기 acceptance 완료라는 뜻이 아니다.

## 서명 CI 설정만 사전 점검

desktop-release.yml의 기본은 unsigned test; publish_release=true에서만 signed build와
DRAFT release 생성. macOS는 hardenedRuntime/notarize와 forceCodeSigning, Windows는
forceCodeSigning 경로를 사용한다. macOS DMG/ZIP 두 architecture와 Windows NSIS,
latest-mac.yml/latest.yml 존재 검사 및 중복 태그 거절을 확인했다.
테스트 패키지는 별도 appId/name, publish=null 및 updater 비활성이다.
인증서·비밀번호·Apple 키의 실제 값/유효성은 열람하지 않았다.

최종 순서: 변경 범위 동결 → 정확 SHA 필수 검사 → 한 번의 동일 소스 패키지 검증 →
서명/공증 제공 여부 확인 → 세 OS/architecture 설치 및 기존 signed 버전 업그레이드 →
사용자 승인 후 공개. 현재 후보에서 빌드·서명·공증·업로드·태그·설치는 실행하지 않았다.
