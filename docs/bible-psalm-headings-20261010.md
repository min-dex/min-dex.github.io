# 다른 역본의 시편 표제 분리

상태: 2026-10-10 사용자의 SQL Editor 결과로 적용 및 백업 236개 확인.
운영 read-only 사후 대조도 통과했다. 관리자 직접 접속 실패는 운영 적용 여부와 별개다.

| 역본 | 변경 대상 | 운영 소제목이 있는 구절 확인 |
|---|---:|---:|
| 쉬운성경 | 5 | 2,341 |
| 우리말 | 115 | 1,810 |
| 바른성경 | 112 | 112 |
| 공동번역 | 4 | 4 |

사용자가 제공한 성경 XML ZIP을 Git 1364e7f1의 importer로 파싱했다.
각 역본의 시편 1절에서 본문이 대괄호로 시작하는 236개를 전부 검토했고,
운영의 본문과 기존 section_title이 원본 파싱 결과와 전부 같음을 확인했다.
전체 변경 전 운영 행 사본은 `/private/tmp/mindex-bible-headings-20261010-before.json`에
있다. 이 파일은 전체 DB 백업이 아니라 해당 행들의 로컬 사본이다.

우리말 117개 후보 중 마가복음 16:9와 요한복음 7:53은 본문이므로 제외한다.
바른성경 118개 중 신약 6개도 제외한다. 한글KJV의 [주]/[하나님]/[데겔]/[베레스],
표준새번역의 대괄호 본문, NIV의 보충 표현도 변경하지 않는다.
쉬운성경은 [제1권] 같은 권 표제 뒤의 <소제목>까지 함께 분리한다.
우리말의 기존 제2권·제3권·제4권은 보존하고 ` · ` 뒤에 시편 표제를 붙인다.
표제의 내용과 길이는 유지하며, 본문 중간의 대괄호와 다른 열은 그대로 둔다.

## 운영 실행

`migrations/2026-10-10-bible-psalm-headings.sql`은 이미 운영에 적용됐다. 다시 실행할 필요 없다.
기존 현대어/예배 migration을 다시 실행하지 않는다.

하나의 DO 블록에서 정확한 원본 fingerprint 확인, 전체 사전 행의 비공개 백업,
수정 및 사후 검증을 처리한다. 임시 테이블은 사용하지 않는다. 하나라도 불일치하면
전체 rollback하며 같은 결과의 재실행은 허용한다. 백업은
`mindex_maintenance.bible_psalm_headings_20261010`에 보관하고 자동 삭제하지 않는다.
성공 시 `bible_psalm_headings_installed`와 역본별 backed_up 값 5/115/112/4가 나온다.

운영에서 236개 전부를 로컬 사전 사본으로 계산한 기대 결과와 비교했다.
text/section_title 분리뿐 아니라 나머지 모든 열의 보존도 확인했다.
제외된 선두 대괄호 구절(우리말 2, 바른성경 6, 표준새번역 8, NIV 8,
한글KJV 996개)의 본문과 소제목도 원본과 일치했다.
비공개 백업 행 수는 사용자의 SQL Editor 결과 기준이며 직접 조회한 것은 아니다.
성경 장 캐시는 12시간 유지될 수 있으므로 이미 읽은 장은 갱신 여부를 별도로 확인한다.
이번에는 다른 작업 중인 화면 파일이나 배포 버전을 수정하지 않았다.

## 검증

`tests/test_bible_psalm_headings.mjs`의 독립 fixture와 실제 운영 사전 사본
(`PSALM_HEADING_BEFORE_JSON`)으로 PostgreSQL 17.6 테스트를 각각 통과했다.
기존 표제 병합, 긴 설명 보존, 신약 본문 제외, 전체 행 백업, 원본 불일치 및
수정 중 오류의 전체 rollback, 재실행, 후속 수정 감지, 브라우저 백업 접근 차단,
별도 세션에서 최종 결과 조회를 확인했다.
