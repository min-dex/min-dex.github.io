# 예배 조작·장비 연동·방송 송출 아이디어

사용자 결정: 2026-10-20. 아래 항목은 민덱스의 후속 기획이며 구현·배포 완료를 뜻하지 않는다.
어린이부에 한정하지 않고 기존 예배·송출·음원 모델을 함께 사용한다.

## 다른 기기에서 원격 조작

휴대폰·태블릿·다른 컴퓨터의 브라우저에서 현재 송출을 조작한다. 특정 기기 전용으로 만들지 않는다.
송출 기기에서 연결을 허용하고 해제할 수 있어야 한다. 연결된 기기는 현재/다음 장과
음원 상태를 확인하고 이전·다음, 재생·정지, 자동 넘김 복귀를 조작하는 방향이다.

구현 전에 연결 인증·만료·권한과 동시 조작 순서를 정한다. 접속 현황 패널만으로
조작 권한을 부여하지 않는다. 중복·지연 명령이 다른 예배나 음원에 적용되지 않아야 하며,
연결이 끊기면 송출 기기의 기존 재생은 유지하고 원격 화면은 끊김을 표시해야 한다.
기존 presenter action 및 음원 제어 경로를 재사용하고 독립적인 재생 엔진을 만들지 않는다.

## 선택 가능한 발표자 집중 보기

기존 민덱스 보기를 기본으로 유지하며 사용자가 집중 보기로 전환할 수 있게 한다.

- 현재 송출 화면을 크게, 다음 화면을 더 작게 나란히 보여 준다.
- 아래에 전체 슬라이드 썸네일과 순서를 두어 이동할 수 있게 한다.
- 현재 순번·음원 상태·자동 넘김 상태와 필요한 조작만 표시한다.
- 편집 영역은 집중 보기에서 숨기고 기존 보기로 돌아와 편집한다.

보기 전환은 조작 화면 배치만 바꾼다. 현재 슬라이드·출력 창·재생 위치·자동 넘김 상태·
미저장 편집 내용을 그대로 유지하고, 보기 전환 때문에 음원을 다시 시작하거나 송출을 끊지 않는다.
기존 P 재생·R 자동 넘김 복귀를 사용한다. 과거 앱의 단축키·전체화면 강제 전환은 복제하지 않는다.
두 보기 모두 같은 presenter state와 동작을 사용하고 별도의 예배 데이터를 만들지 않는다.

## 예배 순서에 맞춘 음향·조명 자동 조작

예배 순서별로 음향기기와 조명기기의 동작을 연결한다. 예를 들어 찬양·기도·설교로
전환할 때 지정한 음향 설정과 조명 장면을 적용하는 방향이다. 구체적인 장비 모델과
제어 방식은 아직 선정하지 않았으며, 지원 여부는 실제 장비 확인 후 결정한다.

순서 이동과 실제 장비 명령 실행을 구분한다. 미리보기·편집·다른 기기의 데이터 갱신만으로
장비가 작동하지 않도록 하고, 운영자가 자동 조작을 켜거나 수동으로 중단할 수 있게 한다.
이전 순서로 돌아가기·같은 순서 재선택·재접속 시 재실행 정책을 명시한다.
오래된 명령이나 중복 명령을 뒤늦게 실행하지 않고, 적용 확인과 실패 상태를 보여 준다.
먼저 실제 장비에 명령을 보내지 않는 모의 실행으로 순서별 동작을 검토할 수 있게 한다.

## OBS 없이 영상 입력·자막 합성·방송 송출

카메라나 외부 영상 입력을 받아 민덱스의 가사·성경·안내 자막을 영상 위에 직접 합성하고,
오디오와 함께 인코딩하여 방송 플랫폼으로 보내는 통합 송출을 구상한다.
OBS 제어 기능에 머무르지 않고 영상 입력 → 화면 합성 → 인코딩 → 방송 송출을 담당하는 방향이다.
구체적인 입력 장비·전송 방식·송출 플랫폼 및 웹/Electron 실행 범위는 후속 설계에서 정한다.

자막을 내부에서 투명 레이어로 그려 영상과 합성하면, 외부 프로그램에 자막 화면을 전달하며
크로마키 색상을 제거하거나 알파채널 지원을 맞추던 경계를 없앨 수 있다.
투명도 처리가 사라지는 것은 아니며 합성기 내부에서 올바르게 처리해야 한다.
외부에서 투명 영상 소스를 받는 경우의 알파 지원, 영상 색 공간·색 범위와 가장자리 품질은
별도 검증 대상이다. 이 구상만으로 기존 출력의 모든 색상 문제가 해결됐다고 보지 않는다.

예배 현장 화면과 방송 화면은 같은 순서를 사용하면서도 배치를 따로 구성할 수 있게 한다.
영상·음성 싱크, 자막 지연, 프레임 손실, 처리 부하, 장시간 방송 및 네트워크 재연결을 검증한다.
방송 시작·종료는 일반 순서 이동이나 화면 보기 전환과 분리된 명시적 조작으로 둔다.
내부 미리보기와 실제 방송 상태를 구분하며, 기존 검증된 송출 경로는 새 경로의 검증 전까지 유지한다.
방송 인증 정보는 공개 저장소나 문서에 기록하지 않는다.

## 범위 밖

성경책 쪽수와 전체 예배 PNG 내보내기는 사용자 결정으로 제외한다.
기존 Keynote 이미지 반입 기능은 이 결정과 별개로 유지한다.
후속 구현 시 현행 UI 계약·서버 저장 정책을 따르고 두 보기 전환 및 연결 해제 중 재생 보존을 검증한다.
