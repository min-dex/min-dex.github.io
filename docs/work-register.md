# 민덱스 진행 중 작업대장

상태 정리일: 2026-11-11. 이 대장은 찬양 데이터 정비와 저장·접속 현황 UI 후속 작업의 현재 인수인계 기준이다. 민덱스 전체 기능의 완료 선언이나 실시간 DB 집계가 아니다. 다른 담당의 설치본·현장 검증은 해당 담당 문서에서 관리한다.

새 작업을 시작할 때 이 대장의 상태와 근거부터 확인한다. 날짜별 문서의 과거 ‘미완료’ 문구만으로 완료된 작업을 다시 실행하지 않는다. 아래 수치는 마지막 검증 기록 기준이며, DB 변경 전 대상의 현재 존재·내용·참조를 재조회한다.

## 상태와 갱신 규칙

- **자료 대기**: 구현·배포가 아니라 곡 식별 또는 입력할 원자료가 부족하다.
- **선택 정비**: 가능한 개선이지만 결함 수정이나 필수 미완료는 아니다.
- **의도적 보류**: 사용자가 유지하기로 했거나 확정 근거가 부족하다. 새 근거 없이 변경하지 않는다.
- **배포 대기 / 운영 검증 대기**: 로컬 검사, 공개 코드 반영, 실제 운영 검증을 각각 구분한다.
- **완료**: 완료 근거와 보호 대상 확인을 남기고, 새 오류가 확인되기 전에는 다시 미결로 올리지 않는다.

작업을 바꾼 담당이 이 대장의 해당 행을 갱신한다. 상태·대상 수의 기준일·다음 행동·완료 조건·근거 위치를 함께 갱신하고, CURRENT/HANDOFF에 같은 목록을 중복 작성하지 않는다. 작업 승인 범위는 사용자 요청을 따르며, 대장에 적혔다는 이유만으로 DB 변경이나 배포가 승인되는 것은 아니다.

## 문서 역할

- 이 대장: 현재 남은 일·보류·완료 경계. 우선순위와 상태를 갱신하는 한 곳.
- [문서 지도](README.md): 기능 계약과 상세 문서의 입구.
- `CURRENT.md` / `HANDOFF.md`: 시작 안내와 기존 날짜별 인수인계. 긴 과거 기록은 근거 이력이며 자동으로 최신 상태를 뜻하지 않음.
- 기능 계약 문서: 앱이 현재 어떻게 동작해야 하는지. 작업대장이 계약을 대신하지 않음.
- `backups/` / `output/`: 원본·변경 전후·검증 영수증. 단순히 오래됐거나 미완료 문구가 있다는 이유로 삭제하지 않음.

이 대장의 갱신은 기존 배포 증거를 반영하며, 실제 예배나 운영 TEST를 새로 저장한 결과를 뜻하지 않는다.


## B01 주보 서버 공통 양식 · 2026-11-21

상태는 로컬 검증 완료·공개 및 설치 앱 배포 대기다. 별도 branch
`codex/native-bulletin-live-repair`, worktree `/tmp/mindex-bulletin-live-repair`에서
토브 설교 요점 통합, 세 부서의 입력칸 이름/표시 서버 설정, 공통 레이아웃의 안전한
자동 반영을 준비했다. 주간 필드 값·명시적 빈 값·개별 조정 속성을 보존한다.
편집/저장/인쇄/송출 중에는 미루며 기존 content-committed와 15초 조회를 쓴다.
후속 요청으로 일곱 양식의 순서표 열 기준선·여러 줄 중앙 정렬을 수정했다.
Chromium/WebKit의 preview/print에서 실제 줄 좌표와 내용 무변경을 검증했다.
설치 앱 두 개의 격리 프로필에서 후보 renderer를 읽는 로컬 예행도 통과했다.
실제 후보 설치본 exact-SHA 확인은 Desktop Packages의 세 플랫폼 검사에 포함한다.

Chromium/WebKit 각 세 부서에서 공통 양식 저장, 표시/숨김/다시 표시, 늦은 응답,
미저장 입력과 송출 보호, 원문 보존을 확인했다. 기존 서버 지면·정렬 검사와
토브 지면/저장/인쇄, shared RPC revision·응답 유실 재시도, 런타임 해시 및
패키지 파일 검사가 통과했다. 보조 workbench 키보드 좌표 검사는 수정 전 HEAD에서도
같은 7.5/8.5 불일치를 재현했다. 해당 보조 테스트는 cloud 기본 entry point가 아니다.
최종 합친 SHA의 필수 GitHub gate와 최초 설치 업데이트·운영 반영 검증은 별도다.
운영 주보·예배 쓰기 또는 DB/schema 변경은 수행하지 않았다.

Release journal `43939a06cd0b4518b6e3b8f5f8c96ca0`, FIFO `d67584b2ea2845a0a5ad413978f08cac`에서 1.0.12 최종 후보를 검증한다.
서버 설정만으로 바꿀 수 있는 범위와 최초 클라이언트 업데이트 경계는
